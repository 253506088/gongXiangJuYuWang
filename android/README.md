# 邻波 Android

Android 8.0+ 的独立应用。1.4.0（版本号 5）安装 APK 后，手机本身运行 HTTP 局域网服务并自动发现其他邻波服务器；无电脑也可让两台 Android 手机互传文件。自有局域网内直接选设备发送，扫码或打开局域网网址后自动连接。发现不到时可输入另一端地址连接，无配对码和接收确认。

视频打开时自动发现同目录和两层 `Subs`、`Subtitles`、`字幕` 下的 ASS/SSA/SRT/VTT。发布组不同也会核对剧名、季数与集号，最佳匹配自动启用；其他字幕可手动选择，也可加载本地字幕。自动读取 UTF-8、UTF-16 和 GB18030，字幕上限 8MB。ASS 原文保留样式，由离线 libass 与随 APK 打包的中文字体绘制；共享目录的 TTF/OTF/TTC 字体也可加载。

播放器全屏保持画面、ASS 字幕和字幕控件在一起。Android 通过原生窗口隐藏系统栏并横屏，退出按钮或系统返回恢复方向和系统栏，视频继续播放。独立的原生视频 CustomView 回退同样支持返回退出；退出全屏不会停止局域网服务。`verify-subtitles.cjs` 与 `tests/SubtitleSupportCheck.java` 验证字幕接口、编码、共享代理、原生全屏及恢复，实际记录见 `VALIDATION.md`。

应用用系统文件选择器发送文件，用系统目录授权选择器添加共享文件夹。共享文件夹只读，同网其他独立主机每 5 秒自动发现并显示其来源；可以直接浏览、下载文件、在线观看浏览器支持的影音。Range 和 HEAD 代理支持拖动视频进度。Android 文件夹 ZIP 下载暂不支持。

1.1.0 增加“链接分享”：通过系统文件选择器只读授权一个文件后，可创建 1 小时、24 小时、7 天或手动撤销的下载链接。文件留在原位置，链接持有者在可连接的局域网内无需配对即可下载；手机上的邻波服务需保持运行。链接、只读文档授权和下载计数在重启后保留，撤销仅删除链接，不删除原文件。`verify-file-links.cjs` 是单文件链接的模拟器协议检查，验证步骤和实际结果见 `VALIDATION.md`。

收到的文件自动保存在收件箱并主动显示，系统通知提供发送者和保存路径。Android 10+ 自动通过 MediaStore 保存到系统公共“下载/邻波”，无需再点下载；同时保留应用专属 Download 目录中的可靠副本。Android 8/9 授予系统存储权限后同样自动保存到“下载/邻波”，未授权时仍保留应用专属副本并显示实际路径。“打开接收目录”打开系统下载列表。公共下载副本在卸载后仍保留。应用运行时显示前台通知；从通知的“停止”按钮关闭服务。部分厂商系统在后台限制网络，需在系统电池设置允许邻波后台运行。

开发环境：JDK 17、Android SDK 35、Gradle 8.14.3。运行根目录的 `打包.bat` 或 `npm run build:android`。脚本会自动复制 `public/` 到 WebView assets，产物 `dist/邻波-LinkWave-Android.apk`。当前产物为开发签名 release build，可直接安装供个人局域网使用；正式商店发布前请设置独立发布签名。

Android 服务自动建立内部任务会话并保存每个文件的已确认上传偏移，强制关闭应用后重新打开仍可续传；重新选择同一文件后继续即可。被系统清理的缓存文件无法恢复，请重新发送。共享目录授权也会在重启后保留。管理共享、单文件链接和设置仅允许本机应用；共享浏览、公共收件下载和主机直接接收对局域网公开。

`verify-direct.cjs` 验证 1.2 免配对自动连接、公开收件、Windows 与 Android 双向直传、两独立 Android 互传、系统通知与自动下载保存、SAF 共享自动聚合和匿名 Range/HEAD 代理；实际结果见 `VALIDATION.md`。旧版 `verify-emulator.cjs`、`verify-android-pair.cjs` 中的配对拒绝断言仅属于历史 1.1 协议。模拟器网络使用本机 TCP 映射，真实 Wi-Fi 组播与各品牌系统后台策略尚需真机验证。
