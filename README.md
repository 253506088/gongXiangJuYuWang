# 邻波 LinkWave

局域网里的文件与影音站。Windows 与 Android 都可以独立充当服务器，电脑、手机通过同一套界面互传文件、共享文件夹、在线播放视频。不需要账号，不经过外部云端。

## 下载成品与启动

- **Windows 10/11 x64**：解压 `dist/邻波-LinkWave-1.3.0-Windows-x64.zip`，双击 `启动Windows.bat`。便携包内已经自带 Node 运行时，不需要安装 Node。浏览器会打开本机管理页面。
- **Android 8.0 及以上**：安装 `dist/邻波-LinkWave-Android.apk`，启动“邻波”。需要允许安装来自当前文件管理器的应用；这是直接分发、使用开发签名的安装包。正式分发时应改用自己的稳定发布密钥。
- **手机免安装**：连接与服务器相同的 Wi-Fi，用浏览器打开桌面页面给出的局域网地址，或者扫描连接二维码。页面自动连接，可以直接收发文件和观看共享视频。

首次启动会自动准备本机子网的文件连接与设备发现；如出现 Windows 管理员授权提示，允许后即可使用。以后只需要双击同一个启动 BAT。Wi-Fi 的“访客网络”“AP 隔离”会阻止设备互通，请使用能互相访问的局域网。

## 互传文件

1. 在 Windows 或 Android 上启动邻波。接收端打开邻波 App，或直接打开此服务器的网页。
2. 在“设备”中选择接收设备，Windows 本机点击“选择文件”或“选择文件夹”。程序直接读取原文件路径发送，不上传到自己、不生成完整临时副本；也可粘贴原路径。
3. Windows 原文件发送只有一条实际送达进度，以 4 MB 分块并支持暂停续传；重新打开页面可继续任务。取消任务不会删除原文件。普通远程网页受浏览器限制，仍先上传到当前主机。

同一服务器内的浏览器之间可以直接选择对方，文件由局域网服务器中转。两台独立主机会通过 UDP 自动发现，点选对方即可发送。Windows、安卓和安卓之间都无需配对或输入验证码。若路由器阻止自动发现，在连接设备中输入对方页面显示的局域网地址即可直连。

独立 Android App 接收中会显示进度；完整文件先进入收件箱，系统 `Download/邻波` 副本在后台保存，并显示通知与保存状态；Windows 主机自动保存到设置的接收目录。单纯手机浏览器收到的文件会显示在收件箱，点击保存即可下载到手机。发送端只有在对方确认接收完成后才显示“已送达”，失败会显示原因和重试入口。

## 单文件链接分享

在服务器本机的「文件互传」页面找到 **链接分享**，点击「创建下载链接」。Windows 使用系统文件选择器，也可以填写文件的完整路径；Android 使用系统文件选择器授权单个文件。选择链接有效期后点击生成，再一键复制局域网 URL。

同一局域网中的任何设备都可以直接打开这个链接下载 **这一个文件**，无需安装邻波、登录或输入配对码。文件从原位置读取，不会先上传或复制到收件箱。可设置 1 小时、24 小时、7 天或手动撤销，默认 24 小时；点击「撤销」立即使链接失效，并保留原文件。分享主机需要保持运行且仍能访问所选文件。生成的链接也支持断点下载。

## 分享视频文件夹

在服务器本机打开“影音共享”，点击“添加文件夹”。Windows 可以选择目录或填写绝对路径；Android 使用系统目录选择器授权访问。连接的设备在共享目录里浏览文件，点击视频即可在线播放，并可拖动播放进度。

共享后，同一局域网的其他邻波主机将在几秒内自动显示该目录，标明来源设备，直接点击即可浏览和在线播放。共享目录为只读，目录外的文件不会被暴露。可以添加多个共享目录，并随时移除。Windows 支持把文件夹打成 ZIP 下载。

在线视频支持浏览器或 Android WebView 可解码的格式，通常是 **MP4（H.264/AAC）、WebM**。MKV、AVI、HEVC、DTS 等能否播放取决于设备的解码能力；不兼容的视频仍可下载到播放器打开。不会自动把整部视频读入内存，也不需要预先上传视频文件。播放用 HTTP Range 按需读取。

## 连接与数据

本机管理页使用 `http://127.0.0.1:53317`；其他设备使用页面中的 `http://局域网IP:53317`。扫码和打开地址都会自动连接。选择主机文件夹、修改设置等管理操作在主机本机完成，已共享目录与接收文件在局域网直接访问。

Windows 便携程序的数据保存在 `LinkWave.exe` 旁的 `data` 目录；源码运行默认保存在项目 `data`。升级时保留此目录即可保留配置、接收文件和下载链接。

保持启动窗口运行；停止服务请在窗口按 Ctrl+C。已收到的文件和配置会保留。

Android 服务会显示常驻通知以维持传输。长时间传输时，在系统电池设置中允许邻波后台运行；不同厂商的省电策略可能会终止后台服务。退出应用页面后，可通过通知重新打开；停止服务会中断当前传输。

## 一键打包

根目录的两个 BAT 用途明确：**`启动Windows.bat` 启动 Windows 完整版；`打包安卓.bat` 编译 Android APK**。双击 `打包安卓.bat` 会自动同步最新界面、编译应用，并打开生成文件所在位置：`dist/邻波-LinkWave-Android.apk`。

开发者重新打包时双击 **`scripts/一键打包.bat`**，生成 Windows EXE、便携 ZIP、Android APK、源码 ZIP 和 SHA-256 清单。脚本先运行集成测试，任何步骤失败都会明确提示，不会把失败当作成功。

源码运行需要 Node.js **22 或 24**；脚本发现 Node 14 时会尝试通过 nvm 切换。Windows EXE 打包使用 Node 22 的内嵌运行时。Android 构建需要 JDK 17、Android SDK 35 和 Gradle；构建脚本会自动定位本机已有工具。

只重新打包 Windows，可以运行：

```powershell
.\scripts\一键打包.bat --windows-only
```

开发与测试：

```powershell
npm ci
npm start
npm test
npm run build
```

自定义端口和数据目录：

```powershell
node server/index.js --port 53317 --data-dir D:\LinkWaveData --name 客厅电脑 --no-open
```

默认 HTTP 端口 **53317/TCP**，自动发现 **53318/UDP**。自定义 HTTP 端口后，请使用界面给出的地址并配置相应防火墙规则。路由器不转发组播时，可以打开远端显示的局域网地址加入。

## 工程结构

`server/` 是 Node 服务端；`public/` 是桌面、手机和 App 共用界面；`android/` 是 Android 原生前台服务、WebView 和文件授权；`scripts/` 是构建脚本；`tests/` 是协议与安全集成测试；`docs/API.md` 是统一协议。

代码采用 MIT 许可证。协议详细说明见 `docs/API.md`。

Windows 浏览器拖放无法提供真实文件路径，因此本机拖入文件会打开系统选择窗口，请在那里选择原文件。这样不会暗中退回上传给自己的旧流程。原文件被修改、替换或移动后，任务会明确提示重新选择。
