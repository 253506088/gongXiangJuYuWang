◈ 邻波 LINKWAVE

让文件，自由流动。

电脑与手机之间的局域网互传、文件夹共享和在线视频。Windows 与 Android 都能独立充当服务器。

Windows：双击「启动Windows.bat」

保持程序运行，浏览器会自动打开管理界面。已经启动时，可以点击下方按钮。

打开邻波管理界面 →

连接另一台设备

  1. 连接到同一个 Wi-Fi 或局域网。
  2. 两端打开邻波，或用浏览器扫描主机页面中的二维码。
  3. 附近设备会自动出现，点选对方即可直接发送，无需配对或验证码。发现不到时，输入对方页面显示的局域网地址。
  4. Windows 和 Android App 自动保存文件并显示收件提示；手机浏览器收到后点击保存即可。

生成一个直接下载链接

在「文件互传」页面点击「创建下载链接」，选择本机文件，设置有效期并生成链接。同一局域网中的设备打开复制的 URL 就能直接下载，无需配对。文件从原位置读取，支持断点下载；可随时撤销链接，原文件保留。分享主机需要保持运行。

把文件夹变成影音站

在主机本机的「影音共享」中添加文件夹。Windows 选择本地目录；Android 通过系统选择器授权目录。其他配对设备可以只读浏览，点击视频、音频或图片预览。MP4（H.264/AAC）和 WebM 最通用，其他格式取决于设备解码能力。

局域网连接

双击同一个「启动Windows.bat」即可启动全部功能并准备局域网连接。首次出现 Windows 管理员授权提示时允许即可；如未允许且其他设备连接不上，可右键同一个 BAT 选择“以管理员身份运行”。默认端口为 53317/TCP 和 53318/UDP，仅允许本地子网访问。访客 Wi-Fi 或 AP 隔离会阻止设备互相访问。

保存与退出

收到的文件保存在程序旁的 data/received，可在偏好设置中更改。共享不会移动或修改原文件。关闭 Windows 程序会停止服务；Android 服务从常驻通知管理。配对和配置文件位于 data，无需分享给其他人。

共享影音会自动显示在其他主机的影音共享中，标明来源，点击即可播放。自动发现、文件互传、影音共享和单文件链接分享都包含在这个 Windows 程序中。使用时只需双击「启动Windows.bat」。
